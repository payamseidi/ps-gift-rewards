# PS Gift Rewards

WooCommerce gift campaign engine by **Payam Seidi** (PS Tools family).

## Development status

**Version:** 0.1.0-alpha.1 — development preview, staging only.

Initial campaign: configurable eligible cart minimum, excluded shipping countries, selected product IDs, single free product and classical cart/checkout integration.

## Installation

Install the packaged WordPress plugin ZIP, not the repository root, via Plugins > Add New > Upload Plugin. WooCommerce must be active. Never enable this alpha on production before checkout testing.
